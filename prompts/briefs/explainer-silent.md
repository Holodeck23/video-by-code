# Silent explainer brief

Create an explanation that works with the sound muted. Confirm the intended viewer, the one claim they should remember and the evidence for it. If content is missing, ask for it before choosing a story.

Aim initially for 20-35 seconds at 1920x1080 and 30fps. Change those values when the actual reading time or delivery channel requires it. Use the selected style throughout the sequence.

Plan five beats: a concrete question or contrast, the starting condition, a visible mechanism, the resulting evidence and a short takeaway. Time each beat from its reading burden. A useful change should occur roughly every 1-3 seconds, but a complex result needs a longer hold.

Write a cue table with start/end, sentence, visible subject, what changes and why. Maintain an object when the next event follows from it. Reserve a scene change for a new context. Never replace the explanation with a slideshow of headlines.

Keep headline type around 90-140px, important labels at least 42px and the decisive value at least 96px in a 1920x1080 frame. Check the composition at phone size. If copy does not fit, edit or split it; do not solve it with tiny text.

Implement a page with canvas id c, positive window.DURATION, optional window.FPS, a window.__ready Promise and synchronous window.__renderFrame(t). Draw any time directly from absolute time and fixed seeds. Reset transforms/compositing each frame; precompute expensive static textures.

Include window.scoreSound(k) only for optional reinforcing effects. Schedule it from the cue table; an arrow's completion and its contact sound share the same timestamp. Keep beds quiet, avoid overlapping accents and leave room before the strongest hit. Sound must never carry essential information alone.

Before full export: produce a hero still, boundary stills and a contact sheet; test seeking out of order. Export with the kit renderer and inspect a full decode, frame count, duration, colour tags and any audio stream. Watch the encoded result from start to finish for readable holds and meaningful progression.

Deliver the source page, cue table, MP4, contact sheet and verification receipt. Distinguish mechanical checks from human approval of the message and visual style.
