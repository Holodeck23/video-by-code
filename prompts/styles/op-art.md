# Elastic Checker Lens

A flat optical painting appears to bend into a lens. The effect is generated by warping an underlying two-colour grid, while labels remain on stable unpatterned plates.

## Palette

| Role | Hex | Use |
|---|---|---|
| Ivory | #f1ecdf | light squares and label plates |
| Black | #151516 | dark squares and type |
| Red | #cb4135 | one selected region |

## Ground and surface

Begin with an ivory field and a 72px checker lattice.
Compute a smooth inverse warp from screen coordinates into lattice coordinates, rather than moving individual cell corners independently.
Use a lens centred at [1120,550] with radius 330px and smooth falloff to zero at its edge.
Keep at least one third of the image optically quiet for reading.

## Mark-making

For a point at radius r, displace its source radius by 0.2*R*sin(pi*r/R) inside the lens; outside use the unchanged coordinate.
Determine checker colour from the parity of floor(u/72)+floor(v/72).
Render at a fixed antialiasing resolution and downsample once; do not blur the completed grid.
A peripheral fold may use 12px sinusoidal displacement with 280px wavelength.
Paint one connected set of cells red, never scattered random red pixels.
Keep edges hard and material matte; this is an optical field, not a shiny 3D ball.

## Type and numbers

Archivo Black at 108px gives a short headline; Space Grotesk 700 at 48px gives labels.
Set a 150px key value on a solid ivory band with 32px padding.
Never deform critical type with the optical warp.
Reveal text using a straight clipping edge over 0.25s.

## Diagrams: arrows, labels, charts

Arrows use hard 10px black segments on ivory strips, ending in 28px heads.
Attach a label to a stable anchor with a short leader crossing the pattern only once.
Encode a comparison as the same grid before and after a measured distortion change.
If displaying data, use a plain inset panel rather than treating checker size as an undocumented scale.

## Motion

Grow lens strength from zero over 0.8s with H.ease.inOutCubic.
For the hold, vary radius by only 4px using sin(t*1.1); stop this breathing while a detailed claim is read.
An error can send one 0.7s radial ripple through the field, with amplitude at most 12px.
All warps are analytic in t; never update a mesh by accumulated velocity.
Use seconds in the shared cue table for all entrances, exits and sound events.

## Scene changes

Compress the pattern into a vertical fold over 0.4s, swap the field behind its narrowest point, then expand over 0.4s.
Keep the label plate fixed across a related comparison so the viewer can judge the changing field.
Avoid high-contrast whole-frame flashing as a transition.

## Finishing passes (run every frame, same strength)

1. Composite the matte checker field.
2. Add label plates and type above the warp.
3. Apply an optional cached paper variation at only 0.012 alpha.
4. Inspect a delivered encode for moire; increase cell size if fine edges shimmer.
Static texture belongs to object or sheet coordinates; cache it with H.offscreen and never reseed it per frame.

## Sound palette

Schedule effects once in window.scoreSound(k); do not trigger sound from the draw loop.
- Element appears: k.play('thud', t, { f: 150, gain: 0.3 }).
- Label lands: k.play('click', t, { gain: 0.1, minor: true }).
- Arrow completes: k.play('tock', t, { gain: 0.18 }).
- Drawing: k.play('pencil', t0, { dur: t1-t0, gain: 0.08, minor: true }); omit this scratch in electronic styles and use a quiet k.tone instead.
- Scene change: k.play('riser', t0, { dur: 0.35, gain: 0.2, minor: true }).
- Wrong / right: k.play('error', t, { gain: 0.25 }) or k.play('success', t, { gain: 0.3 }), tied to the visual evidence.
- Key number: k.play('impact', t, { gain: 0.6 }); this is the strongest accent in the sequence.
- Takeaway: k.play('ding', t, { gain: 0.4 }), followed by a short quiet hold.
- Optional atmosphere: k.bed(0, DURATION, { kind: 'hum', gain: 0.08 }); leave out the bed under narration.
Limit decorative ticks to eight per second and keep only two or three foreground events overlapping.

## Signature moves

- A flat lattice swells into a clearly bounded optical lens.
- One connected red region identifies the variable under discussion.
- A feedback ripple returns through the field after a correction.
- The grid folds without distorting the reading plate.

## Pitfalls

| Failure | Repair |
|---|---|
| A blur imitates depth poorly | Warp source coordinates and retain crisp cell edges. |
| Text vibrates against the checker | Use an opaque label plate. |
| Pattern flickers after compression | Enlarge cells and slow the warp. |
| The effect has no explanatory role | Map one measured parameter to lens strength and label it. |

## Hero frame recipe

1. Draw the 72px grid with a single 330px lens offset to the right.
2. Choose a modest 20% radial warp, keeping cells continuous at the boundary.
3. Tint a connected band of four cells red.
4. Place the headline in a large quiet ivory area at left.
5. Attach one 48px label and one simple arrow to the selected region.
6. View at delivery scale and confirm the field reads as a surface rather than random noise.

Build this still before scoring the motion. Compare subject, hierarchy, medium and text at the intended delivery scale; a lint pass alone is not visual approval.
