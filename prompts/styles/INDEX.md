# Style catalogue

86 technique cards. Choose for the message and medium; a style id is not a proof of visual quality.

Start with one card, render its hero frame, then inspect hierarchy, material and legibility before animating. The kit uses 1920x1080 reference measurements; recompose for vertical output rather than multiplying every value blindly.

## Verification scope

All cards are checked for required sections, known helper names and paired-source wording overlap. Those checks do not establish visual fidelity, factual correctness, rights clearance or production readiness. Render evidence and any human review belong in the production log.
