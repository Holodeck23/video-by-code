# video-by-code agent guidance

Read `CONTRIBUTING.md` when changing or using this kit. At task close, automatically prepare a focused, tested fix or reusable lesson when the work reveals one. Submit a public issue or PR when the user has authorized public contributions and the account is available; otherwise leave a reviewable draft. Keep private production data out of contributions. Do not create noise when there is nothing useful to contribute.

The refactor is on `one-colour`. On that branch, `ARCHITECTURE.md` defines its provisional contracts; existing examples/tools remain the baseline until pilot approval. Generated media belongs in the explicit production folder outside the code checkout.
